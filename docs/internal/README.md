# Internal — agent-session artefacts

This directory holds artefacts from agent-driven development sessions
that don't fit elsewhere in the docs tree. They're not internal in
the "private" sense — the repo is fully open — but they exist for
agent-session continuity rather than external readers.

| File | Purpose |
|---|---|
| [`sprint-state.md`](./sprint-state.md) | Per-sprint checkpoint file. Tracks in-flight branch state across Claude Code sessions so a cold-resume can pick up where the prior session stopped. Updated mid-sprint, archived when the sprint closes. |

External readers can ignore this directory. Start at the root
[README.md](../../README.md) instead.
