## B1 — Workspace lints alignment

**Verdict:** ✅ Already met.

`Cargo.toml` declares:

```toml
[workspace.lints.rust]
unsafe_code = "forbid"

[workspace.lints.clippy]
all = { level = "deny", priority = -1 }
pedantic = { level = "warn", priority = -1 }
module_name_repetitions = "allow"
```

Every workspace crate inherits via `[lints] workspace = true`.
No `unsafe { }` block exists in `crates/**/src/**.rs`; the workspace
lint catches any future regression at compile time.

The gsx-dag side of B1 (mirroring this declaration into
`GlobalSettlementNetwork/gsx-dag/Cargo.toml`) is tracked separately
in that repo.

## B2 — Panic-in-untrusted-input sweep

**Status:** pending.

Scope:

- `crates/gsxdb-server/src/rpc.rs` — untrusted JSON-RPC param parsing.
- `crates/gsxdb-bridge/src/anchor/credential.rs` — malformed
  signature / public-key bytes.
- `crates/gsxdb-bridge/src/anchor/l1_reader.rs` — JSON-RPC response
  parsing (already has flagged HMAC TODO).
- `crates/gsxdb-bridge/src/anchor/types.rs` — `Anchor::hash` + MAC
  paths if anything panics on bad input.

Pattern: replace `unwrap` / `expect` / `panic!` / `unreachable!` on
untrusted bytes with typed errors. Genuinely unreachable cases (post-
invariant guards) keep their `expect` with `#[allow(...)]` + a
one-line rationale comment.
